# Security Policy

## Supported versions

Security fixes are released for the latest minor version of vue-qs.

| Version | Supported |
| ------- | --------- |
| 0.2.x   | ✅        |
| < 0.2   | ❌        |

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report vulnerabilities privately through
[GitHub security advisories](https://github.com/iamsomraj/vue-qs/security/advisories/new).
You will get a response within a few days. Once a fix is released, the advisory is published
with credit to the reporter, unless you prefer to stay anonymous.
